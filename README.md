# AI-Based-Pneumonia-Detection-Using-Deep-Learning
An end-to-end pediatric chest X-ray triage pipeline using fine-tuned ResNet-18. Features custom Thoracic Anatomic Cropping to prevent shortcut learning, calibrated thresholding (98.21% recall, ROC-AUC 0.9609, FP ≤ 60), layer-hooked Grad-CAM explainability, and a standalone TorchScript/Gradio web interface for lightweight, real-time CPU inference.
